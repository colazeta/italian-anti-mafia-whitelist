# Schema 0.1.0

Date: 2026-09-06

This is the first validated database-schema baseline for the Open Italian Anti-Mafia White List Archive.

## Validation gate

The schema was applied successfully on PostgreSQL 18 in GitHub Actions and the full database integrity suite passed both on the pull-request head and again after merge to `main`.

## Included baseline

- canonical Legal Entity model;
- White List registers, regimes, relationships and procedures;
- versioned White List sector taxonomy;
- tri-temporal canonical state (`effective`, `observation`, `system` time);
- source series, editions, captures and immutable content objects;
- versioned parser runs and schema registry;
- entity/procedure mention resolution;
- evidence provenance and processing lineage;
- derived-event input lineage;
- dissemination profiles and canonical-field dictionary;
- PostgreSQL integrity constraints and regression tests.

## Scope

Version 0.1.0 freezes the database architecture only. It does not assert completeness of the national source registry, historical sector schemes before 7 June 2020, source parsers or production data.

## Next phase

Build the national source registry from the Ministry of the Interior's official territorial-office and national White List indexes, then progressively classify each source series, edition model and source schema.
